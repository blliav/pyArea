# pyArea — מדריך למשתמש

!!! warning "גרסת בטא"
    התוסף נמצא בפיתוח פעיל. תצורת **תל אביב** טרם נבדקה על פרויקטים אמיתיים — מומלץ לבדוק את הפלט לפני הגשה.

**pyArea** הוא תוסף לרוויט שמנהל את כל תהליך חישובי השטחים — מהגדרת סכימת החישוב, דרך שיוך השטחים ותיוגם, ועד לייצוא הקבצים להגשה לעירייה.

התוסף בנוי לעבודה לפי דרישות הרשות המקומית: כל עירייה מגדירה שדות, שמות ופורמט ייצוא משלה, ו‑pyArea יודע להתאים את עצמו אליהם אוטומטית.

!!! tip "✨ מגיעים מתקן+ או מתלבטים בין כלים?"
    ראו [מה מייחד את pyArea](features.md) — הפיצ'רים שקיימים רק כאן, וטבלת השוואה מרוכזת.

## למי המדריך הזה מיועד

לאדריכלים ואדריכליות שעובדים ברוויט ומכינים חישובי שטחים להגשה. **לא נדרש שום ידע בתכנות.**

כל השמות של הכפתורים במדריך מופיעים באנגלית, בדיוק כפי שהם מופיעים ברצועת הכלים של רוויט — כדי שתמיד תדעו על מה בדיוק ללחוץ.

## מה יש בתוסף

| פאנל | מה הוא עושה |
| --- | --- |
| **Define** | הגדרת מבנה החישוב ושיוך השטחים — הלב של התוסף |
| **Export** | ייצוא הקבצים להגשה: DXF לשטחים, DWFx לרקעים |
| **Utilities** | כלי עזר לתיקון בעיות נפוצות והגדרות אישיות |

## הרשויות הנתמכות

- **Common (default)** — ארצי ישן (עיקרי ושירות)
- **Common (gross)** — ארצי שטח כולל
- **Jerusalem** — ירושלים
- **Tel-Aviv** — תל אביב

## סדר העבודה בגדול

1. **מגדירים סכימת חישוב** — באיזו עירייה מדובר, אילו תוכניות נכנסות לחישוב ועל אילו גיליונות הן יושבות
2. **משייכים שטחים** — קובעים לכל שטח את סוג השימוש שלו
3. **מייצאים** — DXF לשטחים עצמם, DWFx לרקעים
4. **בודקים ומתקנים** — כלי ה‑Utilities עוזרים לאתר גבולות פגומים, חורים ושמות שגויים
